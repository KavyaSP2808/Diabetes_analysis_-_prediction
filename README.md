🩺 Diabetes Analysis and Prediction

📌 Description
    In order to determine whether a patient has diabetes based on diagnostic measurements, this project uses exploratory data analysis (EDA), preprocessing, and machine learning modeling.
    It includes:
            Data cleaning and feature analysis
            Model training with multiple algorithms
            Hyperparameter tuning
            Using ensemble learning to increase accuracy
            
🚀 Usage
jupyter notebook Diabetes_Analysis_and_Prediction.ipynb

📈 Results
Best performing model: VotingClassifier
Achieved accuracy: 72.7272%
ROC AUC Score: 81.4508%
